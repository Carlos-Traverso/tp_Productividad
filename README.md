
## Qué hace la página

La idea de la pagina es mostrar un tip de productividad "Aleatorio" pudiendo votar positivamente y viendo cuantos votos tiene en ese momento. En caso de que ese tip sea el que tiene mas votos, va a aparecer como Tip mas votado.


## Conceptos usados

- Componentes funcionales.
- `useState`.
- Eventos con botones.
- Renderizado condicional.
- Arrays y búsqueda de máximos.
- Actualización inmutable del estado.
